# Bóc Figma thành Design System - LuxeDrive

## 1. Brand & Style

LuxeDrive dùng phong cách **premium, minimal, corporate modern**.

Cảm giác chính:
- Sang trọng
- Gọn gàng
- Nhiều khoảng trắng
- Ưu tiên hình ảnh xe lớn
- UI giống dịch vụ concierge cao cấp

Các màn hình HTML đang có gồm:
- Landing page
- Browse cars + filters
- Car detail
- Admin dashboard
